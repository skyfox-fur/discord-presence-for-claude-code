# Changelog

## 0.7.0

First public version.

- Rich Presence: current action, chat title or project, cost, context bar, state icons with session figures on hover, member-list text, limit countdown, `💤 Away`.
- Several sessions: one bridge talks to Discord; working sessions take turns, else the last to finish is shown.
- Notifications to a channel webhook and to your DMs through your own bot: task done, question, permission request, error.
- The desktop app's background sessions are neither shown nor announced.
- `showFile` is off by default.
- Windows only.
